# Kuni AI (Python Native Edition)

Полная автономная реплика персонажа **Kuni** без использования Docker.

## 🌟 Особенности
- **Telegram Userbot**: Встроенный клиент Pyrogram с поддержкой лестничных сообщений, распознавания стикеров/фото через Vision и отправкой реакций.
- **Многоуровневая память**:
  - `working_memory.md` (Оперативная память)
  - `diary.sqlite` (RAG-векторный поиск + консолидация во время сна)
  - `long_term_memory.sqlite` (Факты о пользователях и правила жизни)
  - `emotions.sqlite` (Движок эмоций и биоритмов)
  - `goals.sqlite` (Дерево целей и рефлексия)
  - `self_learning.sqlite` (Самообучение и оптимизация инструкций)
- **Прокси-сервер OpenAI**: Прозрачный FastAPI прокси на порту `10434` с поддержкой локальных инструментов.
- **Web-панель и метрики**: Интерактивная веб-панель логов в реальном времени и Prometheus-экспортер на порту `9464`.

## 🚀 Быстрый запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Настройте конфигурацию в `config.toml`:
- Укажите ваш `api_key` и `base_url`
- Укажите `telegram_api_id` и `telegram_api_hash`
- Укажите названия моделей (`chat_model`, `image_model`, `asr_model`)

3. Запустите проект:
```bash
python main.py
```

## 📊 Веб-панель
Откройте в браузере: `http://localhost:9464/`
